# 3D 導演台（Director Console 3D）實作計畫

> v1 計畫・2026-11-09・狀態：v1 已實作（見文末「實作後的調整」）

## 1. 背景與目標

在 Chrome 執行的 3D 預視（previs）導演台：擺放低多邊形單色物件，設定 30 秒內的物件與攝影機運動，用多機位剪輯拍攝並輸出 MP4。低階電腦也要能流暢執行，AI Agent 與人類都要能方便操作。

### 已確認的決策

| 項目 | 決定 |
|---|---|
| AI 操作方式 | 網頁＋本機 MCP 伺服器（伺服器可選；網頁可單獨使用） |
| 人物 | 靜態人偶：整體移動/旋轉＋固定姿勢（姿勢可在時間軸上「瞬間切換」） |
| 攝影機 | 多機位＋剪輯軌 |
| 鏡頭效果 | 焦距/感光元件、魚眼、360° 全景、手持晃動／空拍漂移（不做景深與移軸） |
| 介面語言 | 繁體中文（API、指令、物件類型 ID 用英文） |

## 2. 技術選型

- **前端**：Vite + TypeScript + React 19（只負責面板）。3D 用 Three.js `WebGLRenderer`（WebGL2）命令式驅動，不經過 React 重繪。
- **狀態**：Zustand + Immer patches（復原/重做）；Zod 4 定義專案與指令結構，同時用來驗證、自動產生屬性面板、輸出 JSON Schema 給 AI。
- **影片**：WebCodecs（H.264）＋ Mediabunny 封裝 MP4，逐格離線算圖。
- **伺服器**：Node 24（直接執行 TypeScript，不需編譯）＋ `ws`；MCP 用 `@modelcontextprotocol/sdk`。
- **測試**：Vitest（核心邏輯）＋ 內建瀏覽器實測。

## 3. 架構

```
┌──────────────────── Chrome 分頁（導演台網頁） ────────────────────┐
│ React 面板：工具列／物件庫／大綱／屬性／時間軸／輸出／指令主控台    │
│        │ dispatch(指令)                       ▲ 訂閱狀態            │
│        ▼                                      │                    │
│ core：指令匯流排 ─► Store（專案 JSON＋復原/重做）─► evaluate(t)     │
│        ▲                                      │                    │
│ window.director API                           ▼                    │
│        ▲                 render：Three.js 場景同步／攝影機／鏡頭效果 │
│        │                                      └► export：MP4／PNG   │
│ agent bridge（WebSocket）                                           │
└────────┼──────────────────────────────────────────────────────────┘
         │ ws://127.0.0.1:5178/bridge
┌────────┴──────────── 本機伴隨伺服器（Node，可選） ────────────────┐
│ 提供網頁＋REST /api＋WS 橋接；projects/*.json（監看檔案→即時重載）  │
│ exports/*.mp4                                                       │
└────────▲──────────────────────────────────────────────────────────┘
         │ HTTP（127.0.0.1＋權杖）
┌────────┴─────────┐
│ MCP stdio 伺服器  │ ◄── Claude Code／Claude Desktop／其他 MCP 用戶端
└──────────────────┘
```

設計原則：

1. **單一真相**：專案就是一份人與 AI 都讀得懂的 JSON 文件。
2. **一切修改都是指令**（名稱＋JSON 參數，經 Zod 驗證）。UI、快捷鍵、`window.director`、HTTP、MCP 走同一條指令匯流排：人能做的 AI 都能做，每一步都可復原。
3. **時間求值是純函式** `evaluate(project, t)`：同一份專案、同一時間點，一定得到同一個畫面（亂數都有種子）。輸出影片、截圖、AI 分析都靠它。
4. **物件類型登錄表**：每種類型有參數結構（中文標籤、單位、範圍）與建模函式，屬性面板、驗證和 AI 文件因此自動保持一致。

## 4. 專案資料格式（v1）

- 單位：公尺、度、秒；焦距用 mm。
- 座標：Y 軸向上，地面 y=0；+X 為東（右），−Z 為北（遠離預設攝影機）。
- 旋轉 `[x, y, z]`（度，順序 YXZ）：y = 水平轉向（正值＝俯視逆時針，向左轉），x = 俯仰（正值抬頭），z = 滾轉。物件在 rotation 0 時正面朝 +Z；攝影機在 rotation 0 時朝 −Z 看。
- ID：可讀字串（`hero`、`camA`、`male_2`），唯一且不會變；`name` 可以用中文。

```json
{
  "format": "director3d.project",
  "version": 1,
  "id": "p_k3v9x2ab",
  "name": "街頭對話",
  "settings": {
    "duration": 12, "fps": 24, "aspect": "16:9", "resolution": [1920, 1080],
    "environment": { "preset": "day", "sunAzimuth": 135, "sunElevation": 50, "fog": true, "shadows": false }
  },
  "objects": [
    { "id": "ground", "type": "ground", "name": "地面", "color": "#8a9a7b", "params": { "size": 200 } },
    { "id": "hero", "type": "male", "name": "主角", "color": "#3b6fd8",
      "position": [0, 0, 0], "rotation": [0, 0, 0],
      "params": { "height": 1.78, "pose": "stand" },
      "tracks": {
        "position": { "path": "smooth", "keys": [
          { "t": 0, "v": [0, 0, 0], "ease": "inOut" }, { "t": 4, "v": [3, 0, -2] } ] },
        "params.pose": { "keys": [ { "t": 0, "v": "walk" }, { "t": 4, "v": "stand" } ] }
      } },
    { "id": "camA", "type": "camera", "name": "A 機", "position": [0, 1.6, 6],
      "camera": { "rig": "tripod", "lens": "standard", "focalLength": 35, "sensor": "super35",
                  "lookAt": { "target": "hero", "aim": "head" } },
      "tracks": { "camera.focalLength": { "keys": [ { "t": 0, "v": 24 }, { "t": 6, "v": 85 } ] } } },
    { "id": "camB", "type": "camera", "name": "B 機", "position": [4, 1.5, 2],
      "camera": { "rig": "handheld", "focalLength": 50, "shake": { "preset": "handheld", "amount": 0.4 } } }
  ],
  "cuts": [ { "t": 0, "camera": "camA" }, { "t": 6, "camera": "camB" } ],
  "markers": [ { "t": 3, "label": "主角回頭" } ]
}
```

動畫規則：

- 屬性有關鍵影格就用動畫值，沒有就用靜態值；第一格之前維持第一格的值，最後一格之後維持最後一格的值。
- 每格的 `ease` 決定「從這格到下一格」的速度曲線：`linear`／`in`／`out`／`inOut`（預設）／`hold`（停住，到下一格瞬間切換）。
- position 軌可設 `path: "smooth"`，讓路徑平滑通過每個點。
- 列舉或布林屬性（姿勢、可見度、注視目標）只能 hold 切換。
- 剪輯軌 `cuts: [{ t, camera }]`，硬切。

## 5. 功能規格

### 5.1 物件庫（全部由程式生成，不需外部模型檔）

- **人物**：男、女、小孩、路人（依種子隨機身形與顏色）、人群（N 人合併成 1 次繪製）。姿勢：站、走（跨步定格）、跑、坐、揮手、指向、講電話、雙手抱胸、叉腰、舉手、蹲、躺。頭部有鼻樑記號，看得出面向。
- **地形**：地面、丘陵（種子雜訊，可保留平坦中心區）、水面、道路。
- **建築**：牆（可開門窗）、房間（四牆/地板/天花板/門窗；編輯視角會自動剖開擋住視線的牆）、建築物（樓層、屋頂、窗格）、小屋、城市街區（種子生成，給空拍用）、樓梯、柱子。
- **道具**：方塊、球、圓柱、圓錐、平面、桌、椅、沙發、床、書桌、門、汽車、樹、灌木、路燈、長椅。
- **輔助**：攝影機、注視目標點、走位標記（只在編輯視角顯示）。
- **顏色**：每個物件一個主色；少數物件用頂點色做深淺區分，仍然只占 1 次繪製。

### 5.2 時間軸與動畫

- 長度 1–30 秒（預設 10），fps 可選 24/25/30/50/60（預設 24）。
- 播放、暫停、逐格、跳到上/下一個關鍵影格、循環播放；拖曳時間指針即時預覽。
- 每個物件一列，可展開到各屬性。關鍵影格可拖曳改時間、右鍵改緩動、刪除。「自動關鍵影格」模式下，在某個時間點拖動物件就會自動記錄。
- 3D 視圖顯示移動路徑與關鍵點，可以直接拖點修改。
- 劇本標記：在時間軸上標「台詞 1」「回頭」這類節拍。
- 高階動作：走到某點（依速度算時間、自動面向行進方向）、沿路徑移動、面向某物。

### 5.3 攝影機

- **多機位**：每台可選拍攝方式：腳架、手持、軌道車、搖臂、空拍機（只影響預設值與介面提示）。
- **鏡頭**：焦距 8–600mm（快選 14/18/24/35/50/85/135/200）；感光元件可選全片幅、Super35、APS-C、M4/3、1 吋、手機。即時顯示水平/垂直視角與等效焦距。焦距可設關鍵影格，做變焦或滑動變焦。
- **特殊鏡頭**：魚眼（視角 100–360°，等距/等立體角/球極投影，含「小行星」預設）；360° 全景（等距柱狀，建議 2:1）。
- **晃動**：無/手持/走動/空拍漂移/車載，強度可設關鍵影格；用種子雜訊產生，每次結果相同。
- **注視（lookAt）**：鎖定物件（頭/胸/腳/中心）或某一點。**跟隨（follow）**：保持相對位移，可設延遲。
- **一鍵構圖**：景別（大特寫到大遠景：ECU/CU/MCU/MS/MLS/FS/LS/ELS）× 角度（平視/仰角/俯角/鳥瞰/荷蘭角）× 方位（正面/3/4 側/側面/背面/過肩）。
- **運鏡預設**：推、拉、橫移、升降、搖、俯仰、環繞、變焦、滑動變焦、空拍拉升揭露、空拍飛越、空拍環繞、俯視上升。套用後自動產生關鍵影格，可再微調。
- **畫面比例**：16:9、9:16、1:1、4:5、4:3、1.85:1、2.39:1、2:1、自訂；解析度 720p/1080p/1440p/4K（自動取偶數）。
- **監看**：主視窗可切換編輯視角、俯視圖、攝影機視角、節目（剪輯結果）；子母畫面顯示節目；「多機位監看牆」顯示各機位低解析縮圖，點一下就在時間指針處切換機位（像導播台）。
- **疊加**：三分線、中心點、安全框、其他比例的裁切參考線、HUD（機名/焦距/時間碼）。

### 5.4 專案存取

- 變更後約 1 秒自動儲存。專案管理可以新增（含範本）、開啟、複製、改名、刪除，並顯示縮圖。
- 儲存位置：有伺服器時存成 `projects/<id>.json`（AI 可直接讀寫；網頁偵測到檔案變更會即時重載）；純網頁時存在瀏覽器 IndexedDB。
- 匯入/匯出 `.director3d.json`；把 JSON 檔拖進視窗就能匯入。
- 格式有版本號與遷移機制。
- 範本：空白、街道、室內客廳、辦公室、城市空拍、山丘外景。

### 5.5 輸出

- **MP4（H.264）**：來源可選剪輯軌或單一機位；範圍可選全片或入出點；可設解析度、品質（草稿/標準/高）、壓字（時間碼、機名、焦距）。
- **逐格離線算圖**，不依賴即時播放速度：慢電腦只是輸出比較久，影片不會掉格。顯示進度與剩餘時間，可以取消。
- 另外可輸出目前畫面 PNG，以及分鏡表 PNG（每 N 秒一格，標上時間碼與機位）。
- 有伺服器時，輸出檔同時存到 `exports/`。

- 所有控制項都有 `aria-label`，瀏覽器自動化代理也能可靠地找到按鈕。

## 6. AI Agent 介面

### 6.1 四種操作途徑（同一套指令）

1. `window.director`（瀏覽器內）
2. HTTP：`POST /api/rpc`
3. MCP 工具（Claude Code / Claude Desktop）
4. 直接編輯 `projects/*.json`（附 JSON Schema；網頁即時重載並回報驗證錯誤）

### 6.2 `window.director`

- `help(topic?)`、`listCommands()`（每個指令的 JSON Schema＋範例）、`assetTypes()`
- `run(commands[])`：原子交易，任一失敗就全部回滾，整批只算一次復原。錯誤會回傳 `{code, message, path, hint}`，例如：未知類型 "man"，你是不是要 "male"？
- `get()` / `set(project)`、`evaluate(time)`
- `describe({time, camera})`：文字場景摘要（位置、面向、誰在畫面中、景別）
- `visibility({camera, time})`：每個物件在畫面中的框（0–1 座標）、占畫面比例、是否被遮擋
- `snapshot({camera, time, width})` 回傳圖片；`storyboard({camera, count})` 回傳分鏡表圖片
- `play/pause/seek`、`export({...})`、`projects.*`、`stats()`（fps、繪製次數、三角面數）

### 6.3 指令（第一版）

`project.update`｜`object.add/update/remove/duplicate`｜`key.set/remove/move/clear`｜`cut.set/remove/clear`｜`marker.add/remove`｜`object.moveTo/followPath/face`｜`camera.frame`（構圖）｜`camera.move`（運鏡預設）｜`history.undo/redo`

輸入格式寬鬆：向量可用 `[x,y,z]` 或 `{x,y,z}`，顏色可用 `#hex` 或常見色名，時間單位一律是秒。

### 6.4 MCP 工具

`get_guide`｜`list_projects`｜`open_project`｜`new_project`｜`get_project`｜`run_commands`｜`describe_scene`｜`snapshot`（回傳圖片給 AI 看）｜`storyboard`｜`export_video`（存到 `exports/` 並回傳路徑）

### 6.5 本機伺服器

- `npm start` 啟動在 http://127.0.0.1:5178，同時提供網頁、`/api`、`/bridge` WebSocket。
- MCP 程序啟動時，如果伺服器沒開會自動啟動；需要畫面時如果沒有分頁連線，會自動用 Chrome 開啟網頁。
- 安全：只綁定 127.0.0.1、檢查 Host/Origin（防 DNS rebinding）、使用隨機權杖、專案 ID 只允許白名單字元（防路徑穿越）。
- 文件：`AGENTS.md`（座標、單位、指令、範例流程）、`.mcp.json`（Claude Code 自動載入）、Claude Desktop 設定說明。

## 7. 效能策略

- 按需繪製：畫面沒變化就不重畫，只有播放、拖曳、輸出時才連續繪製。
- 每個物件合併成 1 個幾何體，同色物件共用材質，用 Lambert 平面著色。預設不開即時陰影（可開；另有便宜的腳下圓形陰影）。
- 像素比上限：低/中/高 = 1/1.5/2。
- 魚眼/360 用立方體貼圖：預覽每面 256–512px，輸出時才提高。
- 多機位監看牆與子母畫面用低解析度，播放時降低更新頻率。
- React 不會每格重繪：時間指針與時間碼用 ref 直接更新。
- 輸出模組（Mediabunny）延遲載入；目標首包 < 400KB gzip。
- 目標：Intel UHD 620 等級內顯、100 個物件、20 萬三角面以內，編輯時維持 60fps。

## 9. 實作順序

1. 骨架（Vite/TS/React/Three、目錄、腳本）
2. 核心：結構定義、指令匯流排、復原/重做、時間求值、鏡頭數學（含單元測試）
3. 繪製與物件庫：場景同步、編輯相機、選取與操控器、全部程式建模物件
4. 介面：物件庫、大綱、屬性面板（自動表單）、工具列、快捷鍵
5. 時間軸：播放、關鍵影格編輯、自動關鍵影格、路徑顯示、標記、剪輯軌
6. 攝影機：鏡頭、比例、監看、注視/跟隨、晃動、構圖與運鏡預設、多機位監看牆
7. 鏡頭效果：魚眼、360
8. 專案存取：IndexedDB、自動儲存、專案管理、範本、匯入匯出
9. 輸出：MP4、PNG、分鏡表

## 10. 驗證方式

- **單元測試**：指令與復原、時間求值（緩動、hold、平滑路徑、剪輯切換）、鏡頭數學（焦距與視角換算、構圖距離）、解析度取偶數、格式遷移、伺服器安全檢查。
- **型別檢查**。
- **瀏覽器實測**（用內建瀏覽器）：透過 `window.director` 建立範例場景，截圖目視確認，播放，輸出 2 秒 MP4 後用 Mediabunny 讀回檢查長度、影格數、編碼；魚眼/360 截圖檢查；儲存/載入往返；在終端機修改 `projects/*.json` 驗證即時重載。
- **MCP 實測**：用 SDK 的 client 透過 stdio 呼叫 `run_commands`、`snapshot`、`export_video`。
- **效能**：用「城市街區＋100 人群」範本量 fps 與繪製次數。

## 12. 實作後的調整（依函式庫查證與實測）

- **函式庫版本**：three 0.187（WebGLRenderer，WebGL2）、React 19、Vite 8、TypeScript 7（原生編譯器）、zod 4、immer 11、zustand 5、mediabunny 1.65、@modelcontextprotocol/sdk 1.32。
- **輸出**：使用獨立的離線 WebGL 畫布（`preserveDrawingBuffer`），編輯畫面不受影響。編碼器依序嘗試 H.264 → VP9 → AV1（MP4），都不行再改用 WebM。實測 1080p 12 秒 288 格約 2 秒完成。
- **360° 中繼資料**：Mediabunny 不支援寫入 sv3d／st3d，第一版不注入（README 已註明替代做法）。
- **MCP**：MCP 程序只做轉送。需要時會自動啟動伴隨伺服器，並在沒有分頁時開啟 Chrome。長時間輸出改成工作編號（`export_video` → `get_export_status`）。
- **沒有分頁時**：伺服器直接在 Node 用同一套核心執行指令、描述場景、驗證檔案；只有需要畫面的工具（截圖、分鏡表、輸出）才要求開啟分頁。
- **外部改檔**：伺服器以內容雜湊分辨「自己寫的」與「外部改的」，外部修改在網頁中會成為一個可復原的步驟。
- **安全**：只綁定 127.0.0.1，檢查 Host／Origin（WebSocket 升級也檢查），權杖檔權限 0600，專案 ID 用白名單字元。
- **人物**：依使用者決定採靜態人偶。姿勢由關節角度經正向運動學擺出，再合併成單一網格（約 400 面）。
- **新增範本**：「特殊鏡頭示範」。
